# FTB Ultimine — порт на Minecraft 1.7.10 Forge

Неофициальный порт FTB Ultimine `1.12.2-1.3.4` на Minecraft `1.7.10`.

## Управление

- Клавиша **«Активировать Ultimine»** находится в обычном меню Minecraft:
  **Настройки → Управление → FTB Ultimine**. Её можно переназначить на клавиатуру или кнопку мыши.
- Клавиша по умолчанию: `` ` / ~ ``.
- Удерживайте клавишу и ломайте выбранный блок.
- **Shift + колесо мыши** переключает форму.
- Если сам Ultimine назначен на левый или правый Shift, форма переключается через
  **Ctrl + колесо мыши**, чтобы сочетания не конфликтовали.

## Строгий выбор блоков

Порт ломает только блоки, полностью совпадающие с исходным блоком:

1. тот же зарегистрированный экземпляр блока (тот же `modid:block`);
2. те же метаданные 1.7.10.

Проверка выполняется при построении формы и повторно непосредственно перед добычей.
Поэтому разные породы, варианты одного блока и блоки из других модов не смешиваются.
Настройка старого поведения `mergeStone` оставлена только для совместимости с уже
созданными конфигами и на совпадение не влияет.

## Формы

- `Shapeless` — ближайшие соединённые блоки того же вида, включая диагональные связи;
- `Small Tunnel` — прямой тоннель 1×1;
- `Small Square` — квадрат 3×3 в плоскости выбранной грани;
- `Mining Tunnel` — диагональный тоннель 1×1 вниз;
- `Escape Tunnel` — диагональный тоннель 1×1 вверх.

Обход `Shapeless` сделан итеративным и ограничивается `maxBlocks`, поэтому большие
структуры не вызывают глубокую рекурсию и переполнение стека.

## Сборка

Проект использует RetroFuturaGradle `1.4.0` и Gradle `8.8`.
Gradle запускается на JDK 17, а код мода компилируется Java 8 toolchain.

```bash
gradle build
```

Готовый JAR появится в `build/libs/`.

Для запуска среды разработки:

```bash
gradle runClient
gradle runServer
```

Gradle Wrapper не вложен, поэтому нужен установленный Gradle 8.8 либо wrapper,
сгенерированный командой `gradle wrapper --gradle-version 8.8`.
GitHub Actions workflow устанавливает JDK 8/17 и Gradle 8.8 автоматически.

## Проверка этой редакции

- все Java-исходники успешно прошли компиляционную проверку Java 8;
- отдельный тест подтвердил, что модовый блок с другими метаданными и другой
  модовый блок с теми же метаданными не попадают в одну жилу;
- полноценная сборка с Forge и запуск Minecraft в текущей среде не выполнялись,
  поскольку внешние Gradle/Forge-зависимости здесь недоступны по сети.

## Основные файлы

- `FTBUltimine.java` — события, ломание блоков, сбор дропа, синхронизация;
- `FTBUltiminePlayerData.java` — состояние игрока и кэш выбранной формы;
- `client/FTBUltimineClient.java` — переназначаемая клавиша, HUD и подсветка;
- `shape/BlockMatcher.java` — строгое сравнение блока и метаданных;
- `shape/ShapelessShape.java` — ограниченный поиск соединённых блоков;
- `PORTING.md` — подробности переноса с 1.12.2;
- `CHANGELOG-fixes.md` — перечень внесённых исправлений.
