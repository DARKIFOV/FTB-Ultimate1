# Перенос FTB Ultimine 1.12.2-1.3.4 на Forge 1.7.10

Оригинальный JAR использован как эталон поведения. Классы и критические методы
проверялись по байткоду, поскольку исходники этой конкретной сборки в архиве
не находились.

## Реализовано

- основной мод, клиентский и серверный прокси;
- конфигурация Forge 1.7.10;
- состояние игрока и кэш формы;
- пять исходных форм;
- сетевые пакеты удержания клавиши, смены формы и подсветки;
- перехват дропа и опыта;
- режимы выдачи дропа;
- расход сытости;
- чёрные/белые списки;
- твёрк-рост растений;
- русская и английская локализация;
- подсветка без coremod/ASM.

## Управление

В 1.7.10 используется стандартный `KeyBinding`, зарегистрированный через
`ClientRegistry.registerKeyBinding`. Благодаря этому назначение меняется в
обычном меню управления Minecraft и может быть клавишей клавиатуры либо кнопкой мыши.

В оригинале форму переключает Shift + колесо. Порт сохраняет это поведение и
добавляет разрешение конфликта: если основная клавиша назначена на LShift/RShift,
модификатором смены формы становится Ctrl.

## Совпадение блоков

По требованию этой редакции специальные объединяющие матчеры отключены.
Любая форма использует только:

```text
candidateBlock == originalBlock
candidateMetadata == originalMetadata
```

Это относится и к ванильным, и к модовым блокам. Проверка выполняется:

1. при расчёте списка подсвечиваемых блоков;
2. повторно перед каждым `tryHarvestBlock`.

Повторная проверка исключает добычу блока, который успел измениться после
формирования кэша.

## Формы

Порядок регистрации:

1. `shapeless`;
2. `small_tunnel`;
3. `small_square`;
4. `mining_tunnel`;
5. `escape_tunnel`.

Геометрия восстановлена по байткоду оригинала:

- `Small Tunnel` — линия 1×1;
- `Small Square` — 3×3;
- `Mining Tunnel` — линия 1×1 с понижением Y на каждом шаге;
- `Escape Tunnel` — линия 1×1 с повышением Y на каждом шаге.

`Shapeless` использует обход 26 соседей. В порте он сделан итеративным BFS:
результат остаётся ориентированным на ближайшие блоки, но глубина Java-стека
не зависит от размера жилы.

## Ломание и дроп

Все выбранные позиции, включая исходную, добываются через
`ItemInWorldManager.tryHarvestBlock`. Вложенные `BreakEvent` позволяют модам
защиты отменить каждый блок отдельно. Внешнее событие затем отменяется, чтобы
исходный блок не обрабатывался ванилью повторно.

Во время операции `EntityItem` и `EntityXPOrb` перехватываются. После добычи:

- режим 0 — дроп у исходного блока;
- режим 1 — дроп у игрока;
- режим 2 — предметы в инвентарь, остаток у игрока; опыт сразу игроку.

Расход сытости восстановлен как `exhaustionPerBlock * 0.005` на успешно добытый
блок. Предыдущий черновик применял значение напрямую и завышал расход в 200 раз.

## Отличия от 1.12.2

### Нет coremod

Оригинал внедрял подсветку ASM-хуком в `RenderGlobal`. Порт не является coremod:
сервер отправляет клиенту список позиций, а клиент рисует контуры в
`RenderWorldLastEvent`. Это проще для совместимости сборок 1.7.10.

### API 1.7.10

- собственный `BlockPos` вместо отсутствующего современного класса;
- `Block + metadata` вместо `IBlockState`;
- ручное объединение `ItemStack` вместо capability `ItemStackHandler`;
- `Configuration` вместо современной аннотационной конфигурации;
- проверка открытого GUI вместо `KeyConflictContext.IN_GAME`.

### Строгий режим

Оригинал мог объединять некоторые родственные блоки. В этой редакции такое
объединение намеренно убрано: выбирается только один точный вид блока.

## Значения конфигурации по умолчанию

- `maxBlocks = 64`;
- `dropItems = 0`;
- `exhaustionPerBlock = 4.0`;
- `allowHand = true`;
- `mergeStone = false` и игнорируется строгим матчером;
- `twerkChance = 0.0`;
- `twerkRadius = 4`;
- `twerkPlants = false`;
- `renderTextManually = -1`.

## Проверка

Java-код компилировался с `-source 8 -target 8` против минимальных сигнатур API
Forge/Minecraft 1.7.10. Дополнительно выполнен тест строгого совпадения модовых
блоков по объекту блока и метаданным. Полная RFG-сборка и запуск игры требуют
скачивания Forge/MCP-зависимостей и должны быть выполнены на машине с доступом
к Maven-репозиториям.
