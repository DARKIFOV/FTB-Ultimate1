# Исправления редакции port.2

## По запросу пользователя

- Клавиша Ultimine зарегистрирована в отдельной категории **FTB Ultimine** в
  стандартном меню управления и может быть переназначена.
- Поддержаны назначения на клавиши клавиатуры и кнопки мыши.
- При назначении основной клавиши на Shift смена формы автоматически использует
  Ctrl + колесо мыши.
- Выбор блоков сделан строгим: совпадают только тот же блок и те же метаданные.
- Строгая логика действует для модовых блоков так же, как для ванильных.
- Удалены объединения разных камней, вариантов редстоуновой руды, растений и
  других родственных блоков.

## Исправления механики порта

- `Small Tunnel` исправлен на прямой тоннель 1×1.
- `Mining Tunnel` исправлен на диагональную линию 1×1 вниз.
- `Escape Tunnel` исправлен на диагональную линию 1×1 вверх.
- Исходный блок теперь добывается тем же контролируемым циклом, что и остальные.
- Каждый блок повторно проверяется перед добычей.
- Расход сытости исправлен с прямого значения на `value * 0.005`.
- Дальность серверного ray trace приведена к поведению оригинальной версии.
- Рекурсивный поиск жилы заменён ограниченным BFS.
- Исправлены значения конфигурации по умолчанию, восстановленные по байткоду.
- Уточнено поведение твёрк-роста: вертикальный диапазон ±1, саженцы поддерживаются
  отдельно, остальные растения зависят от `twerkPlants`.
- Убраны вызовы API планировщика, которого нет в Forge 1.7.10.

## Сборка и локализация

- RetroFuturaGradle закреплён на версии `1.4.0` вместо динамической зависимости.
- Gradle закреплён на поддерживаемой версии `8.8` в GitHub Actions.
- Workflow устанавливает JDK 8 и JDK 17.
- Добавлена русская локализация категории управления, клавиши, HUD и форм.
- Версия порта: `1.7.10-1.3.4-port.2`.

## Выполненные проверки

- Java 8 compilation check всех исходников: успешно.
- Тест строгого выбора модовых блоков: успешно.
- Полная Forge/RFG-сборка и запуск в Minecraft не выполнялись из-за отсутствия
  сетевого доступа к Gradle/Forge-зависимостям в рабочей среде.
